# UP_ZOO

Учебный интернет-магазин товаров для животных на Laravel 13 и Bootstrap 5. Проект включает пользовательские страницы магазина и административную панель с ролями администратора и менеджера.

## Запуск

```bash
composer install
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

База данных настраивается через `.env`. Для MySQL укажите `DB_CONNECTION=mysql`, адрес и порт сервера, имя отдельной базы данных, имя пользователя и пароль. Не используйте базу другого проекта. После настройки выполните `php artisan migrate --seed`.

Стартовые категории, бренды, товары и отзывы добавляются командой `php artisan db:seed`. Новые аккаунты получают роль `user`. Назначьте роль `admin` доверенной учётной записи через вашу базу данных перед входом в панель.

Для назначения роли через Tinker выполните `php artisan tinker`, затем:

```php
App\Models\User::where('email', 'ваша-почта@example.com')->firstOrFail()->update(['role' => 'admin']);
```

Для роли менеджера замените `admin` на `manager`. Панель доступна по адресу `/admin`.

## Разделы

- Главная, о магазине, каталог с поиском и фильтрами, акции, новинки и бренды.
- Карточка товара, сессионная корзина и оформление заказа.
- Контакты с формой обратной связи, отзывы покупателей, личный кабинет.
- Регистрация и вход с ограничением частоты попыток авторизации.
- Панель `/admin`: товары, категории, бренды, заказы, отзывы и роли пользователей.
- Администратор управляет каталогом, пользователями и модерацией; менеджер может просматривать отзывы и обрабатывать заказы.

Пользовательские страницы и панель управления используют Bootstrap 5 и адаптивные стили в `public/css/upzoo.css`. Для стилей и скриптов Bootstrap требуется доступ к CDN.
