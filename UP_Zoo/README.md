# UP_ZOO

Учебный интернет-магазин товаров для животных на Laravel 13 и Bootstrap 5. В проекте есть главная страница и пользовательские разделы магазина; административная панель не входит в эту версию.

## Запуск

```bash
composer install
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Для разработки база данных по умолчанию — SQLite (`database/database.sqlite`). Стартовые категории, бренды, товары и отзывы добавляются командой `php artisan db:seed`.

## Разделы

- Главная, о магазине, каталог с поиском и фильтрами, акции, новинки и бренды.
- Карточка товара, сессионная корзина и оформление заказа.
- Контакты с формой обратной связи, отзывы покупателей, личный кабинет.
- Регистрация и вход с ограничением частоты попыток авторизации.

Пользовательские страницы используют Bootstrap 5 и адаптивные стили в `public/css/upzoo.css`. Для стилей и скриптов Bootstrap требуется доступ к CDN.
